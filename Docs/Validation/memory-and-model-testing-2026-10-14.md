# Training memory and standalone model testing

Measured on an Apple M2 Max with 64 GiB unified memory. Execution receipts,
before/fixed binaries, isolated regression packages, full test logs and UI renders
are stored outside the repository in
`~/Library/Application Support/Loom Factory/Validation/2026-10-14-memory-retention`.

## Retained GPU allocations

The interrupted Bricks depth run used Pyramid width 47, four blocks, 1024-pixel
crops, batch 1, 44 pairs and AdamW. Its log ends at update 1262 during epoch 29.
The run's log and checkpoint occupy about 16 MB. Validation was disabled and the
checkpoint interval was 100 epochs; only the first-update checkpoint was saved.
The saved run and original source images were retained unchanged.

The native session previously lacked local autorelease pools. A long synchronous
detached worker retained temporary Objective-C/Metal wrappers and GPU storage
across graph executions. Training, optimization, evaluation, prediction, feed
construction and tensor readback now drain their temporary objects locally.
Persistent parameters, gradients and optimizer moments retain explicit owned
buffers. The blocking graph API, output initialization and numerical operations
remain the same.

Identical synthetic input, seed and configuration measured:

| Measurement | Previous code | Fixed code |
|---|---:|---:|
| Completed updates | 100 | 1500 |
| Final process physical footprint | 9.428 GiB | 3.866 GiB |
| GPU allocation growth after update 20 | approximately 57 MiB/update | 0 bytes |
| Warm median seconds/update, updates 20–100 | 0.41248 | 0.41253 |

The fixed run completed in 619.15 seconds, beyond the interrupted run's update
count. Physical footprint grew 8.91 MiB between updates 20 and 1500, while Metal
allocations stayed at 3.748 GiB. The first 100 losses and gradient norms were
identical between the previous and fixed binaries. These are execution and
lifetime measurements, not evidence of generalization or learned map quality.
The separate bounded decoded-image cache still uses up to 8 GiB on this machine.

The new regression covers repeated train/optimizer/evaluate/predict and checkpoint
readback without a caller autorelease pool. Against the previous source it fails
with 212 MiB additional Metal storage and 264 MiB additional physical footprint;
the fixed source passes the same test.

## Test Model workspace

Open **Test Model** in Loom Room, or choose **Test model** on a saved run. Select
exported model weights or its saved checkpoint, then choose an image file or a
diffuse from the dataset and click **Run Model**. One saved version and an unpaired
image suffice. Saved epoch counts distinguish the actual checkpoint from later
unsaved training progress. No external AI service is involved.

Inference runs off the main actor and supports progress and Stop. It validates
saved architecture, project, dataset, map and weight checksum. Native coordinates
are preserved using overlapping tiles up to 1024 pixels, without resizing or
rewriting source images. Predictions are feathered in overlaps; normal vectors
are normalized after blending. Tiled predictions can differ from whole-image
inference. CPU buffers scale with the original image dimensions.

Results are published atomically under `.loom-factory/model-tests/<UUID>/` with a
full native-size 16-bit PNG and provenance record. PNG values use fixed [0,1]
quantization, without per-output normalization. Input and saved weight hashes
are checked before publication. The viewer provides input/output, Fit/100%/200%
zoom, Save Output, Show Output and Show Test Folder. Model-test previews preserve
stored orientation so their pixel coordinates match inference. Save Output copies
the generated bytes and rejects original images, including symlink aliases.

CPU tests cover native rectangular tile coverage, small images, normal blending,
16-bit scalar and normal roundtrips, saved model/checkpoint selection, identity
and checksum rejection, cancellation cleanup, changed originals and byte
preservation. UI tests cover one-run/unpaired/external inputs, stale weights,
source switching, export protection and offscreen layouts. Interactive desktop
automation was unavailable (`Sky Computer Use native pipe startup failed`);
offscreen rendering is not an interactive UI check.

The clean staged-source package passed all 38 native tests, 117 core tests
(three optional tests skipped), and 36 UI tests. This includes the existing real
1K residual-network gradient regression and the new memory test. A separate
opt-in execution loaded the interrupted Bricks run's actual saved checkpoint and
generated a 1024 × 1024 PNG from its sandstone diffuse without changing its hash.
That checkpoint contains only one optimizer update; its output does not represent
the 28 completed but unsaved epochs. The result is retained under
`.loom-factory/model-tests/c930635a-daaa-409e-aafb-4bcce3017448/`.
